# Cariboo Ridge Outdoor Services — Website Starter

A responsive, static multi-page website that works on desktop, tablet, and mobile.

## Pages
- `index.html` — Home
- `services.html` — Services and details
- `about.html` — Owner introduction
- `gallery.html` — Project gallery
- `contact.html` — Quote request form

## The easiest way to edit it
1. Open `js/site-config.js` in any text editor.
2. Update the phone number, add the business email, and adjust the service area.
3. Open the HTML pages to edit the wording. Each page is labelled and uses plain HTML.
4. Replace or add photos in `assets/`, then update the image filenames in the HTML.
5. Edit colours and layout in `css/styles.css`. The main colours are at the top under `:root`.

## Important before publishing
- The supplied logo artwork displays `519-444-4903`. Verify this number before launch; it may not match the intended BC service area.
- Add a real business email in `js/site-config.js`. The contact form uses `mailto:` and opens the visitor's email app; it does not send/store submissions. For a true website form, connect a form service or backend.
- The supplied graphics are used as example brand/gallery images. Replace with genuine completed project photos as available.
- Check that the owner bio, services, service area, and all claims are accurate.
- Test on a phone after hosting.

## Preview locally
Open `index.html` in a browser. Some mobile/browser features can behave slightly differently from a hosted site, so test the final hosted version too.

## Publish free (simple option)
You can upload the extracted folder to GitHub and enable GitHub Pages, or use Netlify Drop. Keep the folder structure intact so CSS, JavaScript, and image links work.
